# Stock Report

สร้างรายงานสถานะสต็อกสินค้าทั้งหมด ในรูปแบบมาตรฐานที่อ่านง่ายและสรุปสั้น พอสำหรับส่งต่อทีม

## วิธีดึงข้อมูล

ดึงข้อมูลสินค้าทั้งหมดจากตาราง `Product` (ผ่าน Prisma หรือ query โดยตรง) โดยต้องได้ฟิลด์
อย่างน้อยนี้ต่อสินค้า: `sku`, `name`, `quantity`, `reorderPoint`

สถานะคำนวณตามกฎเดียวกับ `lib/stock-status.ts` (`getStockStatus`):

- `quantity <= 0` → หมดแล้ว
- `quantity <= reorderPoint` (แต่มากกว่า 0) → ใกล้หมด
- นอกนั้น → ปกติ

## รูปแบบรายงาน

หัวรายงานเป็นวันที่ (รูปแบบ `YYYY-MM-DD`) ตามด้วยตาราง Markdown เรียงตาม SKU:

```
# รายงานสถานะสต็อก — 2026-07-12

| SKU       | ชื่อสินค้า      | คงเหลือ | จุดสั่งซื้อ | สถานะ         |
| --------- | --------------- | ------- | ----------- | -------------- |
| SKU-1001  | กระดาษ A4       | 120     | 50          | ปกติ           |
| SKU-1004  | หมึกพิมพ์สีดำ   | 8       | 10          | ⚠️ ใกล้หมด     |
| SKU-1007  | ปากกาลูกลื่น    | 0       | 20          | 🔴 หมดแล้ว     |
```

กฎการ mark สถานะในคอลัมน์สุดท้าย:

- `quantity == 0` → `🔴 หมดแล้ว`
- `quantity > 0 && quantity <= reorderPoint` → `⚠️ ใกล้หมด`
- นอกนั้น → `ปกติ`

## สรุปท้ายรายงาน

ปิดท้ายด้วยส่วนสรุปเสมอ:

```
## สรุป

- จำนวนสินค้าทั้งหมด: 7 รายการ
- ใกล้หมด: 1 รายการ (SKU-1004)
- หมดแล้ว: 1 รายการ (SKU-1007)
- ต้องสั่งซื้อเพิ่ม: SKU-1004, SKU-1007
```

"รายการที่ต้องสั่งซื้อ" = รวมทั้งสินค้าที่ ⚠️ ใกล้หมด และ 🔴 หมดแล้ว ทั้งหมด

## กฎการเขียนโค้ดตัวอย่าง

โค้ดตัวอย่างใด ๆ ในรายงานหรือใน skill นี้ (TypeScript/JavaScript) ห้ามใส่ semicolon
ให้สอดคล้องกับ convention ของโปรเจกต์ใน `CLAUDE.md`

ตัวอย่าง query ด้วย Prisma (ไม่มี semicolon):

```ts
const products = await prisma.product.findMany({
  orderBy: { sku: 'asc' },
})

const lowStock = products.filter((p) => p.quantity <= p.reorderPoint)
```

## หมายเหตุ

- ถ้าไม่มีสินค้าที่ใกล้หมดหรือหมดสต็อกเลย ให้ระบุในสรุปว่า "ไม่มีรายการที่ต้องสั่งซื้อ"
  แทนการเว้นว่างไว้
- ถ้าผู้ใช้ขอเฉพาะ "รายงานสินค้าใกล้หมด" ให้แสดงเฉพาะแถวที่เป็น ⚠️ หรือ 🔴 ในตาราง
  แต่ยังคงสรุปจำนวนสินค้าทั้งหมดไว้ท้ายรายงานเหมือนเดิม
